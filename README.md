# سامانهٔ برنامه و تقویم شیفت دبیرستان افشارچی

برنامهٔ مدیریتی مدرسهٔ **دوشیفته** (افشارچی ۱ و افشارچی ۲) که هر هفته به‌صورت چرخشی صبح/بعدازظهر می‌شوند؛ تا دبیر هیچ‌وقت شیفت خودش را گم نکند.

## نماها (۳ تب)

| نما | رفتار |
|---|---|
| **روزانه** | همیشه «امروز» (`new Date()`) — بدون ناوبری. همهٔ کلاس‌ها، دبیران و زنگ‌های امروز هر دو مدرسه (اول شیفت صبح). در پنجشنبه/جمعه، پیام تعطیلی + پیش‌نمایش روز درسی بعدی. |
| **هفتگی** | همیشه «هفتهٔ جاری» — بدون ناوبری. برای هر مدرسه یک جدول با **۷ ستون روز** (شنبه تا جمعه، با تاریخ جلالی هر روز) و سطرهای کلاس؛ ستون «امروز» مشخص است. |
| **تقویم ماهانه** | پیش‌فرض ماه جاری و قابل تعویض با دکمه‌های ماه قبل/بعد و **انتخاب‌گر ماه جلالی** (فقط ماه/سال). محور X روزهای هفته، محور Y هفتهٔ اول تا ششم. در هر خانه معلوم است کدام مدرسه صبح و کدام بعدازظهر است. کلیک روی نام مدرسه ← مودال جزئیات همان روز و شیفت. |

### جستجو (یک اینپوت برای هر سه نما)
- بدون جستجو: همهٔ دیتا نمایش داده می‌شود.
- با جستجو (دبیر، درس، کلاس، مدرسه…): فقط کلاس‌های مرتبط می‌مانند، **زنگ منطبق هایلایت** و متن منطبق با `<mark>` نشان‌دار می‌شود؛ بقیهٔ زنگ‌های همان کلاس کم‌رنگ می‌شوند تا جای زنگ در برنامه دیده شود.
- در تقویم ماهانه ابتدا فقط **بلاک مدرسه/شیفتی** در هر خانه می‌ماند که عبارت جستجو در برنامهٔ همان روزش هست (دبیر اگر در هر دو مدرسه باشد، هر دو بلاک می‌مانند) و داخل مودال هم همان فیلتر نمای روزانه اعمال می‌شود.
- چیپ‌های «جستجوی سریع دبیر»، میانبر `/` برای فوکس، و پشتیبانی از ی/ک عربی، نیم‌فاصله و ارقام فارسی/لاتین.

### قاعدهٔ چرخش شیفت
مبدأ: چهارشنبه **۱ مهر ۱۴۰۵** — افشارچی ۱ صبح، افشارچی ۲ بعدازظهر. از شنبهٔ بعد شیفت‌ها جابه‌جا می‌شوند و این چرخش **هر شنبه** ادامه دارد. رنگ هویت هر مدرسه ثابت است (افشارچی ۱ سبزآبی، افشارچی ۲ بنفش)؛ صبح = بلاک روشن + خورشید، بعدازظهر = بلاک تیره + ماه.

## اجرا

ماژول‌های ES نیازمند سرو شدن روی `http` هستند (باز کردن مستقیم با `file://` کار نمی‌کند):

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```

## ساختار فایل‌ها

```
index.html            پوسته: هیرو، نوار تب‌ها+جستجو، اسپرایت آیکون، مودال و پیکر
css/app.css           سیستم طراحی کامل (RTL، ریسپانسیو، چاپ)
js/
  config.js           مدارس، زنگ‌ها و ساعت شیفت‌ها، روزهای هفته، مبدأ شیفت
  data.js             دیتای برنامهٔ هفتگی کلاس‌ها (نمونه؛ قابل جایگزینی با API)
  jalali.js           آداپتور تقویم جلالی روی date-fns-jalali (+ فال‌بک Intl)
  shift.js            منطق چرخش شیفت و «وضعیت الان»
  search.js           نرمال‌سازی فارسی، فیلتر و هایلایت — مشترک هر سه نما و مودال
  dom.js              ابزار DOM و آیکون‌ها
  components.js       کارت کلاس/زنگ و سرگروه‌ها (مشترک روزانه و مودال)
  views/daily.js      نمای روزانه
  views/weekly.js     نمای هفتگی (۷ ستون)
  views/monthly.js    تقویم ماهانه
  month-picker.js     انتخاب‌گر ماه جلالی
  modal.js            مودال جزئیات روز
  app.js              state سراسری، تب‌ها، رویدادها و رندر
```

## تقویم جلالی — date-fns-jalali

از CDN مرجع استفاده شده است:

```
https://cdn.jsdelivr.net/npm/date-fns-jalali@4.4.0-0/index.min.js
```

این آدرس یک ماژول ESM است که ۲۰۰+ تابع را re-export می‌کند؛ برای اینکه مرورگر صدها درخواست نزند، در `js/jalali.js` فقط **زیرماژول‌های لازم** (format، addMonths، startOfWeek با شروع شنبه، eachDayOfInterval، locale فارسی `fa-IR` و…) از همان نسخه و همان CDN با `import` داینامیک خوانده می‌شوند. اگر CDN در دسترس نباشد، سامانه به‌صورت خودکار روی تقویم فارسی داخلی مرورگر (Intl) ادامه می‌دهد — خروجی هر دو مسیر روی بازهٔ ۴۶۰ روزه تست و یکسان بوده است.

## نکات توسعه

- تعویض دیتا: فقط `js/data.js` را عوض کنید (یا همان ساختار را از API برگردانید)؛ بقیهٔ سامانه مستقل از دیتاست.
- ساعت زنگ‌ها و مبدأ شیفت در `js/config.js` هستند.
- فایل `Afsharchi_complete (1).html` نسخهٔ ناقص توسعه‌دهندهٔ قبلی است و دست نخورده باقی مانده؛ این سامانه از نو و فایل‌بندی‌شده نوشته شده است.
